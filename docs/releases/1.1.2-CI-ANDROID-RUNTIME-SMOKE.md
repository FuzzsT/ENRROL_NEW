# DPC-AIO 1.1.2 — CI Android Runtime Smoke

Patch 1.1.2 extends 1.1.1 Build/Runtime Readiness with an executable AOSP Device Owner runtime gate.

## CI runtime gate

After `assembleEnterpriseRelease` and QR/checksum verification, GitHub Actions starts a fresh API 35 x86_64 Google APIs emulator with KVM acceleration. The workflow then:

1. installs `DPC-AIO-enterprise-release.apk`;
2. requests Device Owner with `adb shell dpm set-device-owner io.dpcaio.app/.AioDeviceAdminReceiver`;
3. launches the DPC dashboard;
4. invokes the `android.permission.DUMP`-protected `VERIFY_DIAGNOSTICS` receiver as shell;
5. requires runtime readback `deviceOwner=true`, the expected DPC version, and a non-empty module inventory;
6. stores `dist/android-runtime-smoke.json`;
7. refreshes SHA-256 evidence before any continuous/tag release publication.

The AOSP smoke does not claim Samsung Knox/SEM/OEM hardware verification. Those states remain separate.
