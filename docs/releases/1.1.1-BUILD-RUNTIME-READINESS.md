# DPC-AIO 1.1.1 — Build / Runtime Readiness

Patch 1.1.1 preserves the 1.1.0 enterprise/Knox/SEM/OEM behavior and focuses on reproducible Android builds.

- Pins NDK `28.2.13676358` and CMake `3.22.1` in the version catalog and native diagnostics module.
- Adds `tools/android_build_preflight.py` with stable `BUILD_READY` / `BUILD_BLOCKED` JSON evidence.
- CI executes the preflight after Android SDK and release-signing material are prepared, before Gradle compilation.
- CI uploads `build-environment.json` even if a later build step fails.
- Local source environment remains `BUILD_BLOCKED` when Android SDK/build-tools/NDK/CMake are unavailable; this state is not promoted to APK/runtime verification.
