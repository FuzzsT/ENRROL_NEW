# DPC-AIO Companion publication boundary

The current Full Upgrade prepares a validated local/private skills-only plugin package. Public Plugin Directory publication remains blocked until all publication prerequisites are verified.

Stop before publication when any of these remains unresolved:

- Publisher identity is not verified for the intended public directory account.
- Stable public website, privacy policy, terms, and support URLs have not been verified.
- The target repository or release channel is not writable with authorized credentials.
- Plugin validation, public-exclusion checks, deterministic packaging, or required repository checks fail.
- A release version/tag would overwrite or ambiguously reuse an immutable published version.

Do not fabricate listing URLs, publisher identity, repository ownership, review status, or submission success. The plugin source intentionally omits unverified public listing URLs.
