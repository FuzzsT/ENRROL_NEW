# DPC-AIO 1.0.1 Build Resolver Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Resolve exact Gradle/JDK/Android SDK requirements and produce evidence-based offline/online build readiness and build results.

**Architecture:** Python host tooling reads the existing wrapper and environment without mutating project configuration. It returns structured readiness codes and runs the exact resolved Gradle only after preflight.

**Tech Stack:** Python 3, Gradle Wrapper metadata, Android SDK command-line tools, subprocess.

**Spec:** `docs/superpowers/specs/2026-08-23-dpc-aio-1.0.1-hardening-verification-design.md`

## Global Constraints
- Never substitute another Gradle version.
- Never modify `gradle-wrapper.properties` during resolution.
- Missing tooling is BLOCKED, not a source-code FAIL.
- Offline build invokes Gradle with `--offline`.
