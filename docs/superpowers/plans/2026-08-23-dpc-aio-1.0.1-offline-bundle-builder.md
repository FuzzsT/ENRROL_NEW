# DPC-AIO 1.0.1 Offline Bundle Builder Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, validate, sign, verify, inspect, and preview offline deployment bundles without placing private signing material in outputs.

**Architecture:** A Python package owns canonical manifest generation and file inventory. Ed25519 signing is detached; APK metadata inspection is best-effort through local Android tooling and never inferred from filenames.

**Tech Stack:** Python 3, hashlib, zipfile, cryptography Ed25519, optional aapt2/apkanalyzer/keytool.

**Spec:** `docs/superpowers/specs/2026-08-23-dpc-aio-1.0.1-hardening-verification-design.md`

## Global Constraints
- Private key input remains external and is never copied to bundle/release.
- Every file hash is verified before signing/verification success.
- Unknown metadata is reported as unavailable, not guessed.
