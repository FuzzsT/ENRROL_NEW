# DPC-AIO 0.8.0 Credentials Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add safe CA certificate, key-pair and certificate-delegation administration without private-key export.

**Architecture:** Core credential descriptors use byte arrays/metadata but never expose private-key export APIs. Android mapping is isolated in `policy-android`; UI uses Storage Access Framework inputs and explicit destructive confirmations.

**Tech Stack:** Kotlin/JVM 21, DevicePolicyManager, KeyChain/public certificate APIs, existing delegation module.

**Spec:** `docs/superpowers/specs/2026-08-22-dpc-aio-0.8.0-enterprise-operations-center-design.md`

## Global Constraints
- Public Android APIs only.
- No private-key dump/export path.
- Preview API 10000 remains unavailable/hidden metadata only.
- Delegation uses DPM delegated scopes, not deprecated cert-installer shortcuts.
