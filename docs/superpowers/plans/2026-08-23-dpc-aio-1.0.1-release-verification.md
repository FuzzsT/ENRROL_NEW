# DPC-AIO 1.0.1 Release Verification Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire 1.0.1 tooling into host/pre-push/release verification and package evidence without converting unrun device/build checks into PASS.

**Architecture:** Existing release scripts run new 1.0.1 contract tests. A release report records layered statuses and is copied into final staging together with tools and test target source.

**Tech Stack:** Python 3, Bash, existing release scanners/plugin checks.

**Spec:** `docs/superpowers/specs/2026-08-23-dpc-aio-1.0.1-hardening-verification-design.md`

## Global Constraints
- Version `1.0.1`, versionCode `19`, companion `0.1.8`.
- Private keys and transient caches/build outputs are excluded.
- Build/device checks remain BLOCKED/NOT_RUN when not executed.

---

### Task 1: Version and gate wiring
**Files:** Modify app version config, plugin metadata, `tools/run_host_tests.sh`, `tools/release/verify-before-push.sh`; Create `tools/tests/test_101_release_gate_contract.py`.
**Interfaces:** Host/pre-push include all new 1.0.1 contracts.
- [ ] Write failing version/release gate test requiring 1.0.1/19/0.1.8 and new test names.
- [ ] Run; expect FAIL on 1.0.0 metadata.
- [ ] Update metadata and scripts.
- [ ] Re-run; expect PASS.

### Task 2: Release verification report
**Files:** Create `tools/verify_aio/release_report.py`, `RELEASE-VERIFICATION.json`; Test `tools/tests/test_101_release_report.py`.
**Interfaces:** Report supports PASS/FAIL/SKIP/BLOCKED/NOT_RUN and layered verification booleans/statuses.
- [ ] Write failing tests asserting BLOCKED build/device states remain false and no secret fields are serialized.
- [ ] Run; expect FAIL.
- [ ] Implement report generation and release defaults from current evidence.
- [ ] Re-run; expect PASS.

### Task 3: Full verification and packaging
**Files:** Update release notes/validation/checkpoint/package info.
**Interfaces:** Final passworded ZIP and SHA-256.
- [ ] Run all new contract tests, complete host-core tests, provisioning server tests, secret/non-SDK/project gates, plugin determinism, and actual Gradle build attempt.
- [ ] Record exact evidence; unresolved environment build remains BLOCKED/UNVERIFIED.
- [ ] Stage without caches/private keys/build outputs, retest final extracted ZIP, then create password `123` archive and SHA-256.
