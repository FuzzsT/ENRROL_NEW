# Privacy

DPC-AIO Companion is a local skills-only package. It defines instructions and bounded local scripts and does not operate a plugin-owned remote service or telemetry endpoint.

The public plugin package excludes repository secrets, signing material, lab credentials, APK outputs, Android SDK/NDK content, and Gradle caches. Any repository data accessed during a workflow remains subject to the host environment, repository permissions, and tools the user explicitly authorizes.
